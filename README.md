# DFIR Case Study

> **Status: planned.** The case will be added once the investigation is complete.

Phase 5 of my home lab: a simulated attack on my lab environment, investigated end to end and written up as a case report, the way a real digital forensics and incident response engagement would be.

## Planned scope

- A realistic attack chain simulated on the lab (domain controller, Windows endpoint, SIEM)
- Evidence acquisition and handling with a documented chain of custody
- Timeline analysis across endpoint artefacts and SIEM data
- Indicators of compromise and MITRE ATT&CK mapping
- A case report with findings, root cause and recommendations
